# Тексты для вкладки «Конфиденциальность» (Chrome Web Store)

Вставить как есть. Галочку про соответствие Правилам программы на этой же вкладке нужно поставить вручную.

Удалённый код: в форме выберите, что **удалённый код не используется**. Ниже — текст, если поле всё равно требуют.

Главная и поддержка: сначала выложите файлы из этой папки (`homepage.html`, `support.html`, `privacy.html`) на любой публичный HTTPS (GitHub Pages, Netlify, свой домен). Пока URL не открывается в браузере без авторизации, кабинет будет писать «URL недоступен».

---

## Описание цели (single purpose)

Подмена на веб-страницах заданных пользователем имён, названий и фраз на выбранный им текст, в том числе близких по написанию вариантов, без облачного перевода и без ИИ.

---

## Подробное описание (если поле в «Конфиденциальность», минимум 25 символов)

Расширение хранит папки и пары замен только в chrome.storage.local на устройстве пользователя. Оно читает видимый текст открытой вкладки, чтобы найти заданные фрагменты и подменить их. Текст страниц, история и пары никуда не отправляются: нет сервера, аналитики и рекламы. Кнопки «Сканировать» и «Как было» работают только с текущей вкладкой.

---

## Обоснование activeTab

Разрешение activeTab нужно, чтобы по нажатию «Сканировать» или «Как было» в попапе обращаться только к активной вкладке пользователя: применить пары выбранной папки или вернуть исходный текст. Расширение не запрашивает доступ к вкладкам в фоне и не читает список всех открытых вкладок.

---

## Обоснование scripting

Разрешение scripting нужно, чтобы при сканировании текущей вкладки выполнить уже входящие в пакет файлы match.js, storage.js и content.js, если на этой странице ещё нет content script (например, вкладка открыта до установки или это особый URL). Скрипты только локальные, из zip расширения. Удалённые скрипты не загружаются.

---

## Обоснование storage

Разрешение storage нужно, чтобы сохранять на устройстве папки, пары замен, язык интерфейса и правила сопоставления в chrome.storage.local. Данные не синхронизируются через аккаунт Google и не уходят на внешний сервер. Пользователь может выгрузить или импортировать JSON сам.

---

## Обоснование доступа к хостам (host / &lt;all_urls&gt;)

Доступ ко всем сайтам нужен, потому что пользователь читает автоперевод книг и новелл на разных доменах (ридеры, переводчики страниц, документы). Content script подменяет только текстовые узлы по парам, которые задал пользователь. История просмотра не собирается, содержимое страницы не загружается в интернет. Без широкого host permission замены не сработают на неизвестном заранее сайте книги.

---

## Обоснование удалённого кода

Удалённый код не используется. Все JavaScript-файлы поставляются внутри пакета расширения (popup, match.js, storage.js, content.js). chrome.scripting.executeScript подключает только эти локальные файлы. Нет eval, нет загрузки скриптов с CDN или своих серверов, нет динамического импорта по URL.

---

## Как используются данные (если есть отдельное поле / чекбокс)

Используются только данные, которые пользователь сам ввёл (пары замен, настройки) и видимый текст текущей страницы для локальной подмены. Эти данные не продаются, не передаются третьим лицам и не используются для рекламы. Соответствует Правилам программы для разработчиков Chrome Web Store: данные применяются исключительно для заявленной функции замены текста.

---

## «Какие данные пользователей вы планируете собирать» (галочки)

Это публичная страница продукта. Google считает «сбором» не только отправку на сервер, но и доступ/хранение у расширения.

**Отметить только:**

- **Содержимое сайтов** — да. Content script читает видимый текст страницы, чтобы найти и подменить пары. Обработка только на устройстве, загрузка текста в интернет нет.

**Не отмечать:**

- Идентифицирующая личность — не спрашиваем имя, email, паспорт.
- Медицина, финансы, пароли, переписка, геолокация — не нужны и не читаются (поля ввода, чаты и пароли расширение специально пропускает).
- История веб-поиска — URL и список посещений не сохраняем.
- Действия пользователей — нет кейлоггера, кликов, скролла «на сбор»; MutationObserver только чтобы снова применить замены при изменении DOM.

Пары «было → стало», которые человек сам ввёл в попап, — это его настройки в `chrome.storage.local`, не персональные данные из списка выше.

Дальше в форме обычно спрашивают, для чего: **только основная функция расширения** (подмена текста). Не продаёте, не используете для рекламы, не передаёте третьим лицам, не отслеживаете пользователей.
