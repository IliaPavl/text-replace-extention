Support

Replace Similar Text is a local text-replace tool for auto-translated pages. It does not require an account.

Common issues

  • Reload the tab after installing, then open the folder and press Scan.
  • Chrome Web Store and some chrome:// pages cannot be modified.
  • Use Restore in the folder if you want the original page text back.
  • Export JSON from the popup to back up folders.
